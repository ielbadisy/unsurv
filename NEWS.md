unsurv 0.7.5
------------
- `unsurv_stability()` now resamples patients only by default: a nonparametric bootstrap of size
  n (`frac = 1`, was 0.5), no curve noise (`jitter_sd = 0`, was 0.01), no weight perturbation
  (`weight_perturb = 0`, was 0.3), and the tie-breaking jitter of the fit
  (`eps_jitter = fit$eps_jitter`, was 0.02). The old feature jitter added 2 m sd^2 to every squared
  distance, so its effect grew with the number of grid points, and in simulations it lowered the
  stability of the true number of clusters and pulled the most stable K towards 2. Stability
  indices with default arguments are higher than before; pass the old values to reproduce them.
  The perturbations remain available as sensitivity analyses.

unsurv 0.7.4
------------
- Default time weights (`weights = NULL`) gave the first and last grid points a full interval
  instead of half of one, i.e. twice their trapezoid weight. They now follow the trapezoid rule
  (bug fix). Weighted distances, and hence clusterings, silhouettes and stability scores with
  default weights, change slightly; results with user-supplied `weights` are unchanged.
- `unsurv_stability()` refitted every resample with trapezoid weights, ignoring the `weights` of
  `fit`; it now uses `fit$weights` (bug fix; results unchanged for fits with default weights).
- `unsurv_stability()` gains a `seed` argument (default `NULL`, previous behaviour).
- `plot.unsurv()` drew a legend with black lines only, unrelated to the coloured curves. A new
  `col` argument (default one colour per cluster, as before for the curves) now sets both the
  curves and the legend (bug fix).
- Removed a dead duplicate definition of `unsurv()` in `R/plot.R` (the one in `R/unsurv.R` was
  always the one used). The help page no longer repeats the usage, description and details;
  the function and its arguments are unchanged.

unsurv 0.7.3
------------
- Vignette: the METABRIC cohort is now cited from the **biobench** package
  (was **biostatlab**). Documentation only; no code or API changes.

unsurv 0.7.2
------------
- Dropped the `tidyr` dependency: `plot_surv_medoids()`/`plot_surv_samples()`'s
  `pivot_longer()` reshape step is replaced by a new internal
  `.pivot_longer_simple()` (base R).

unsurv 0.7.1
------------
- Dropped the `dplyr` dependency: `plot_surv_medoids()`/`plot_surv_samples()`
  used `dplyr::starts_with("t")` (tidyselect column matching) and
  `dplyr::mutate()` only inside their internal reshape step, both replaced
  with base R (`grep("^t", names(x))`, plain column assignment). `tidyr`
  (the actual reshape call, `pivot_longer()`) is unaffected.

unsurv 0.7.0 (2026-08-30)
-------------------------
- Added the published method reference (El Badisy, 2026, Bioinformatics Advances,
  <doi:10.1093/bioadv/vbag218>) to `DESCRIPTION` and switched `CITATION` to the
  article entry.
- The introductory vignette now includes the paper's worked example: clustering
  survdnn-predicted survival curves for the METABRIC cohort, run from a small
  pre-computed set of curves shipped in `inst/extdata/metabric_survdnn_curves.rds`
  (regenerated by `data-raw/metabric_survdnn_curves.R`). The shipped object holds
  only model-predicted probabilities and observed `(time, status)` --- no
  METABRIC covariates or identifiers --- so the example needs no extra packages
  at build time.

unsurv 0.6.0 (2026-07-22)
-------------------------
- Added `unsurv_compare()` to summarize and compare multiple cluster partitions
  (e.g., an `unsurv` curve-based partition against scalar-risk or covariate-PCA
  baselines) against observed survival outcomes, reporting cluster-size balance,
  Adjusted Rand Index agreement against a reference partition, and per-cluster
  Kaplan-Meier medians.
- Added `autoplot()`/`plot()` methods for `"unsurv_compare"` objects, producing
  Kaplan-Meier curves faceted by comparison method.

unsurv 0.5.0 (2026-03-12)
